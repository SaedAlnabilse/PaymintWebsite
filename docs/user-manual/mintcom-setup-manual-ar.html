دليل إعداد مينتكوم

إعداد الأجهزة والشبكة وتشغيل أول موقع

1. متطلبات التشغيل

  • جهاز لوحي أو هاتف متوافق (Android / iOS) لتطبيق نقاط البيع.
  • اتصال إنترنت مستقر (واي فاي مفضّل).
  • حساب مينتكوم وموقع مُنشأ من بوابة المالك.
  • طابعة إيصالات اختيارية (حرارية) وماسح باركود عند الحاجة.

2. إعداد الموقع والحساب

  1. سجّل الدخول كـ مالك على mintcompos.com.
  2. أنشئ موقعًا واختر الدولة — تُضبط العملة تلقائيًا حسب الدولة.
  3. احفظ معرّف تسجيل دخول الموقع وكلمة المرور.
  4. أضف المنتجات والموظفين والأدوار قبل يوم الافتتاح.

3. تثبيت تطبيق نقاط البيع

  1. ثبّت التطبيق من المتجر أو حزمة APK المعتمدة.
  2. أدخل معرّف تسجيل دخول الموقع.
  3. سجّل دخول الموظف برقم PIN.
  4. افتح وردية تجريبية وتحقق من الطباعة والدفع.

4. الطابعة والماسح

طابعة الشبكة

وصّل الطابعة بالراوتر، اعرف عنوان IP، ثم من الإعدادات ← الطابعة أدخل IP والمنفذ (عادة 9100) واختبر طباعة.

بلوتوث

فعّل البلوتوث، اقرن الطابعة من نظام الجهاز، ثم اخترها داخل مينتكوم.

ماسح الباركود

الماسحات التي تعمل كلوحة مفاتيح عادةً لا تحتاج إعدادًا إضافيًا — امسح على شاشة البيع لإضافة الصنف.

نصيحة: اطبع إيصالًا تجريبيًا قبل استقبال العملاء.

5. الشبكة والعمل دون اتصال

مينتكوم يمكنه متابعة عمليات البيع الأساسية عند انقطاع الشبكة ثم المزامنة عند عودة الاتصال. أبقِ الجهاز مشغّلًا ولا تمسح بيانات التطبيق أثناء الانقطاع.

مهم: لا تعِد تثبيت التطبيق أو مسح البيانات أثناء وردية مفتوحة دون مزامنة.

6. قائمة تحقق ما قبل الإطلاق

  1. اللغة والعملة والضريبة صحيحة.
  2. المنتجات والأسعار ظاهرة في نقاط البيع.
  3. الموظفون وأرقام PIN تعمل.
  4. الطابعة والمسح والدفع مجرّبة.
  5. خطة الاشتراك أو التجربة مفعّلة.

7. الدعم
